# G7 Link brand files

The G7 mark, shared with G7 Linux.

| File | Use |
| --- | --- |
| `icon.svg`, `icon-flat.svg` | The full-color app icon |
| `icon-mono.svg` | The mark alone in white, for one-color uses |
| `icon-512.png` | The app icon at 512 x 512 |
| `icon-256.rgba` | The app icon at 256 x 256 as raw RGBA, which `desktop/app/src/mark.rs` draws every size from |
